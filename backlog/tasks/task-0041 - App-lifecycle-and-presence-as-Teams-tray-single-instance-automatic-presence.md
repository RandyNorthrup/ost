- Built: StatusNotifierItem tray (Qt.labs.platform) with the same menu and the OST logo + live presence badge (generated by desktop/assets/tray/make.py); Quit OST; single instance over $XDG_RUNTIME_DIR/ost-desktop.sock (second launch raises the window, exits in ~76 ms); log file $XDG_STATE_HOME/ost/ost-desktop.log; Collect Support Files as Teams (Desktop folder, then opens it).
- Verified live on Hyprland/waybar: menu tree over D-Bus, close hides to tray, relaunch restores, Collect Support Files, Quit (socket removed).

- Presence researched in Teams' worker (docs/spec/presence.md, by agent from modules 93846/67431/64130): three published pairs only; Away is the service's; on desktop "inactive" = machine locked; user.activity over Trouter (twice on connect, on change, ack in 10 s); hourly heartbeat; Teams-V2-Desktop headers; endpoint create only for a new epid or 240 s after the last success.
- Built: engine presence state machine (endpoint_pair, set_call_state, publish_endpoint with the 240 s rule, publish_state, heartbeat, delete_endpoint) with Teams' bodies/key order/headers; Offline sends activity OffWork; Trouter: user.activity twice on connect, lock immediately / unlock debounced 1 s, ack timeout → reconnect, hourly heartbeat, no 120 s re-PUT; desktop: logind lock watcher (session via auto Id → GetSession; suspend = locked), call/sharing state → Busy/InACall or DoNotDisturb/Presenting; endpoint deleted on sign-out.
- Verified live: Trouter acks (6:::n+[]), second report at 10 s, lock hint → inactive at once, unlock → active after 1 s (SetLockedHint, no real lock). Call-state publish to be verified in the next live call test. Left for AC3-5: status duration UI + dedupe, Set status message dialog, DND toast filter.
