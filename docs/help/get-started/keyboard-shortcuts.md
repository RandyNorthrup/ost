# Use keyboard shortcuts

OST uses Teams' keyboard shortcuts. Press **Ctrl+.** (period) to see them
all. Some you'll use often:

| Shortcut | What it does |
|---|---|
| Ctrl+E | Search |
| Ctrl+F | Find in the open chat or channel |
| Ctrl+, | Settings |
| Ctrl+. | Keyboard shortcuts |
| F1 | Help |
| Ctrl+Shift+T | Pin the window on top |
| Ctrl+Alt+Shift+R | Report a problem |
