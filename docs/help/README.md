# Help for OST

These articles are what OST's Help (F1) shows: they're built into the app,
so Help works offline. Each folder is one of Help's categories (its
`index.md` holds the category's name and description); each article starts
with `title` and `description` (and `featured: true` for Featured topics).

Found something wrong? Edit the article and open a pull request, or use
Feedback ▸ Report a problem in OST.
