# Report a problem

1. Select **Settings and more (···) ▸ Feedback ▸ Report a problem**, or
   press **Ctrl+Alt+Shift+R**.
2. Say what happened. Add a screenshot (**Capture screenshot**) or files
   if they help.
3. Choose whether to share OST's recent log lines, and whether we may
   contact you.
4. Select **Submit**. OST opens the report in your browser as an issue on
   OST's GitHub, filled in. Paste your screenshot (Ctrl+V), then select
   **Create**.

Reports are **public**. Names, addresses and message text are masked in
the shared log lines. See the [privacy statement](https://github.com/RandyNorthrup/ost/blob/main/PRIVACY.md#feedback).

**Give a compliment** works the same way. **Suggest a feature** opens the
project's Ideas, where you can vote on what others suggest.
