# Work with channel tabs

A channel's tabs sit next to its name: **Posts** (or Conversation),
**Shared** (the channel's files), and tabs such as **Page** and **Notes**.

The selected tab's **⌄** menu has its actions, for example Rename, Move left,
Move right, Copy link to tab and Remove. Select **+** to add a tab.
