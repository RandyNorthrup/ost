# Post in a channel

1. Open the channel and select **Post in channel**.
2. Add a subject if you like, then write your post. Select **Announcement**
   to make it stand out with a banner.
3. Select **Post**.

To answer a post, select **Reply in thread** under it. Followed threads
show in **Chat ▸ Followed threads**.
