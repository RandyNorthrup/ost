# React to, edit or delete a message

Point at a message to see its reactions and its **···** menu.

- **React:** pick an emoji, or **+** for any emoji. Select a reaction again
  to remove it.
- **Edit** (your own messages): change the text, then press Enter.
- **Delete** (your own messages): it's replaced by "This message has been
  deleted." Select **Undo** to bring it back.
- **···** also has Reply with quote, Forward, Copy link, Save this
  message and Pin for everyone.
