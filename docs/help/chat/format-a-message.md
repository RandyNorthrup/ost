# Format a message

Select **Format** (the pen with the A) under the message box to open the
formatting bar. It has bold, italic, underline, strikethrough, colours,
headings, lists, quotes, links, inline code and code blocks.

- A **code block** colours its code. It detects the language as you type,
  or you can choose one under **··· ▸ Display option**.
- In a channel, formatting also adds **Add a subject** above the message.
- Press **Shift+Enter** for a new line. Whether **Enter** sends the message
  or starts a new line is set in Settings ▸ Chats and channels.
