# Schedule a message

1. Write your message.
2. Select **+** (Actions and apps) under the message box, then **Schedule
   message**.
3. Pick a date and time, and confirm.

The message waits in the chat, greyed, with when it will go. Select it
to **edit** the text or time, or **delete** it so it never goes.
