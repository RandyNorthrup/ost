# Start a chat

1. In **Chat**, select **New message** (the pen) at the top of the list.
2. Type the names of the people you want to chat with. Add a few people to
   make a group chat, and give it a name if you like.
3. Type your message and press **Enter**.

Your own chat (your name, marked **(You)**) is a place for notes,
files and links for yourself.
