# Find something in a chat

1. In a chat or channel, select **Find** (the magnifying glass) at the
   top, or press **Ctrl+F**.
2. Type what you're looking for. Results show as you type, grouped by
   month, with your words highlighted.
3. Narrow them down with the filters:
   - **Messages ▾ / Files ▾** switches between messages and files.
   - **Date ▾** offers Today, Yesterday, This week, This month, or a range.
   - **From ▾** limits results to one person.
   - **Attachment** keeps messages with files, and **Mentions** keeps
     messages that mention you.
4. Select a result to jump to it in the conversation. Your words are
   marked there too.

In a post's own window, the same search is **Find in post** (··· or
Ctrl+F).
