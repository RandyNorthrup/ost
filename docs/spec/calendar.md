# Teams' calendar — spec (TASK-0050)

Measured in Teams on the web as ost-test1 on 2026-11-17, inside OST's own
web profile on linuxlt (1852×988 viewport, 1x). Teams' calendar is Outlook
on the web's calendar hosted in an iframe
(`outlook.office.com/hosted/calendar/…`); its scheduling form and event
page for Teams meetings ("calv2") are Teams' own. The same app runs in
Teams desktop.

## Requests

| What | Request |
| --- | --- |
| Week data | Outlook's `outlookgatewayb2/graphql` and `service.svc?action=GetCalendarView`; OST reads Graph `/me/calendarView` with `Prefer: IdType="ImmutableId"` (the ids Outlook uses). |
| RSVP (card, event page, "RSVP with note") | `POST outlook.office.com/owa/service.svc?action=RespondToCalendarEvent&app=Calendar`, empty body; the JSON in the `x-owa-urlpostdata` header: `RespondToCalendarEventJsonRequest` with `EventId` (the occurrence, or the series), `Response` Accept/Decline/Tentative, `SendResponse` ("Email organizer"), `Notes` `<div>note</div>` (HTML), `Attendance` 0, `Mode` 0; headers `action`, `x-req-source: Calendar`, `prefer: IdType="ImmutableId", exchange.behavior="IncludeThirdPartyOnlineMeetingProviders"`.  Follow is `Response: "Tentative"` with `Attendance: 3` (Teams desktop bundle: AttendanceType None 0, InPerson 1, Online 2, Follow 3); Outlook then marks the event free and its subject "Following: ". The token is the hosted calendar's (app ceb96695-e468-48ba-ba21-35e2a242d396 through Teams' broker, scope outlook.office.com/.default); the service also needs a browser User-Agent, `x-owa-hosted-ux: true`, `x-owa-host-app: teams_desktop` and the JSON encoded as encodeURIComponent (a "+" for a space fails with TimeZoneException). |
| RSVP from Teams' own event page (calv2) | `PUT {mt}/v2.0/me/calendars/events/{iCalUId}/respond?eventType=Single|Occurrence|RecurringMaster&eventStartDateTime=…` `{responseType: Accept|TentativelyAccept|Decline, sendResponse, comment, attendance: None|Follow}` (Teams' calendar service bundle). OST uses it when the sign-in is device code (no broker). |
| Send update / Cancel on a channel meeting (organizer) | `PUT {mt}/v2.0/me/calendars/events/{objectId}?isOnlineMeeting=…` `{updatedCalendarEvent}`; `PUT {mt}/v2.0/me/calendars/events/{objectId}/cancel` `{cancellationMessage}` (objectId: the REST id). The middle tier's update needs the meeting's chat in `skypeTeamsData` ("Conversation id cannot be null" without one), so it is for Teams meetings only. |
| Send on your own event (a Teams meeting too) | Teams' event page is Outlook's form for every event you organise, Teams meetings included (winpc, 2026-11-23; a Teams meeting's update was captured the same way, plus an `IsDefaultPreferences` extended property OST doesn't send): `POST outlook.office.com/owa/service.svc?action=UpdateCalendarEvent&app=Calendar` (from the hosted calendar's worker), `UpdateCalendarEventJsonRequest` with the header's `TimeZoneContext` (the mailbox's zone, e.g. "Pacific Standard Time") and a body of `EventId` (the immutable id), `ItemChange {Updates, ItemId}`, `EventScope` 0, `ShouldSendUpdateToAttendees` false, `TargetAudience` 0, `ClientSupportsIrm` true. `Updates` holds only what changed, as `SetItemField`s on a `CalendarItem` (`Subject`, `Start`/`End`, `Location`, `Body`, `LegacyFreeBusyStatus` as `FreeBusyType`…); when the attendees changed, the whole `RequiredAttendees`/`OptionalAttendees` lists (`{Mailbox: {Name, EmailAddress, RoutingType: "SMTP"}}`) and `AddedRequiredAttendees`, `AddedOptionalAttendees`, `AddedResources`, `RemovedRequiredAttendees`, `RemovedOptionalAttendees`, `RemovedResources`. Exchange sends the attendees the update (new attendees an invitation). When only the attendees changed (title, times, place and repeat as they were, attendees before and after), Outlook asks first: "Send update" / "You've made changes to the attendee list. Do you want to send updates to only added/removed attendees or all of them?" with "Only added/removed attendees" (primary, `TargetAudience` 2) and "All attendees" (`TargetAudience` 1). |
| Change a series' repeat | On an occurrence the page says "You're editing one event in the series." with "Edit series" and "Edit this and all following events"; Edit series shows "Occurs every Tuesday from 3:00 PM to 3:30 PM effective Tue 11/24/2026 until Tue 12/15/2026". Send with a new repeat asks "Edit series" / "If you changed specific events in the series, your changes will be canceled and those events will match the series again." (Save, Cancel), then sends `UpdateCalendarEvent` on the series master's id with `SetItemField` `Recurrence`: `{__type: "RecurrenceType:#Exchange", RecurrencePattern: {__type: "WeeklyRecurrence:#Exchange", DaysOfWeek: "Tuesday Thursday", FirstDayOfWeek: "Sunday", Interval: 1}, RecurrenceRange: {__type: "EndDateRecurrence:#Exchange", EndDate: "2026-12-15", StartDate: "2026-11-24"}}` (each also with a `__typename`; others: `DailyRecurrence {Interval}`, `AbsoluteMonthlyRecurrence {DayOfMonth, Interval}`, `AbsoluteYearlyRecurrence {DayOfMonth, Month}`, `NoEndRecurrence {StartDate}`), `EventScope` 0. |
| Form opens | `PUT {mt}/v2.0/me/calendars/schedules` (free/busy, "AttendeeAvailabilityOnly"; answers each person's events and the organizer's time zone, e.g. `PacificSt`), `POST {mt}/beta/me/calendarEvents/privateMeeting/schedulingService/create` `{"isStreamEnabled":false,"meetingType":"Scheduled"}` (the meeting's thread, links, dial-in). |
| Send / Save | `POST {mt}/v2.0/me/calendars/default/events?isOnlineMeeting=true&shouldDecryptData=true` with `{calendarEvent, schedulingServiceEvent}`; the event: attendees (organizer first, `role` Admin, `type` Organizer/Required/Optional), `bodyContent`, `startTime`/`endTime` with offset, `eventTimeZone` (PacificSt), `eventType` Single/RecurringMaster, `eventRecurrencePattern` `{patternType (Daily 1, Weekly 2, Monthly 3, RelativeMonthly 4, Yearly 5…), daily/weekly/monthly/yearly: {interval, daysOfTheWeek, dayOfMonth…}}`, `eventRecurrenceRange` `{startDate, endDate}`, `isAppointment` (no attendees), `location`, `showAs`, `reminderMinutesBeforeStart` 15, `skypeTeamsData`. | Channel meeting | `POST {mt}/v2.0/groups/smtp:<team mailbox>/calendars/default/events?isOnlineMeeting=true&shouldDecryptData=false`, the event alone, the team's mailbox as a Required attendee, `mailboxAddress`, `skypeTeamsData` `{"cid":"19:…@thread.tacv2","uid":"8:orgid:…","type":0}`; the service posts the meeting in the channel. |
| Cancel a channel meeting | `PUT {mt}/v2.0/groups/smtp:<mailbox>/calendars/events/<iCalUId>/cancel` `{conversationId, messageId, rootMessageId, cancellationMessageFormat:"The meeting \"{0}\" is cancelled", fetchEventContract:{eventType, eventTimeZone:"UTC", startTime}}`. |
| Meet now | `POST {mt}/beta/me/calendarEvents/privateMeeting/schedulingService/create` `{"meetingType":"MeetNow","isStreamEnabled":false,"subject":"Meeting with OST Test 1","unhideChatThread":true}`, then pre-join on its join link. |
